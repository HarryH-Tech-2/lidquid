How do QR codes work, and are they safe to scan?

By the Lidquid team · Updated November 2, 2026 · 4 min read

the short answer

A QR code is a square picture that stores a short piece of text, almost always a web address. Your phone camera finds the three big corner squares, reads the pattern of dark and light modules, and turns it back into text. Scanning is safe if you check the address before you open it, because the risk is the link, not the code.

What is a QR code?

A QR (quick response) code is a grid of small dark and light squares that encodes data, most often a URL. It was invented in 1994 for tracking car parts and is now printed on menus, parcels, posters and laptop lids. The code doesn't do anything itself. It is only a way to hand a phone some text without anyone typing it.

How does a phone read a QR code?

The camera looks for the three large squares in the corners, which tell it the orientation and size, then reads the rest of the grid as ones and zeros and decodes them into text. If the text looks like a web address, the phone offers to open it.

QR codes include error correction, so a code can still be read when part of it is scuffed, dirty or covered. That's why a slightly worn sticker on a laptop lid usually still scans.

What's the difference between static and dynamic QR codes?

A static code stores the final address directly. A dynamic code stores a short address on a tracking service, which then redirects to the real destination. The picture looks the same either way.

Is it safe to scan a QR code?

Usually yes. Scanning only reads text. The danger is what the text points to, such as a fake login page or a prompt to install something. Treat a QR code like a link someone handed you on paper.

  • Read the preview. Most phones show the web address before opening it. Check the domain.
  • Watch for stickers over stickers. In public places, a code can be stuck over a real one. If it looks pasted on, skip it.
  • Don't enter passwords or card details on a page you reached from an unexpected code.
  • Be wary of urgency, such as "pay a fine now" or "claim a prize".
Rule of thumb: if you wouldn't tap that link in a text from a stranger, don't tap it from a QR code either.

What can a site learn when I scan?

A site you open can see what any website sees: your device type, rough location from your network, and the time. Scanning doesn't hand over your contacts or photos. A dynamic code also lets whoever runs it count that a scan happened.

When someone scans a sticker on a Lidquid laptop, they see the brand's content, not the owner's name or details. Owners likewise don't see who scanned.

Do QR codes work on stickers and laptop lids?

Yes, if the code is large enough, high contrast and flat. A square of at least a few centimetres, dark on light, with a blank border around it, scans reliably at arm's length. Glare, curved surfaces and tiny printing are the usual causes of failed scans.

Placement matters too: a code on a laptop lid is only seen by the people sitting behind you. More on that in QR code sticker marketing for local businesses.

How do I make my own QR code?

Use a generator, type in the address, and download the image. For a code you'll print and can't easily replace, consider a dynamic one so you can fix the destination later. Always scan your printed version with a phone before you rely on it, and note that your own test scans may inflate any count.

What can a QR code actually contain?

Mostly a web address, but also plain text, a phone number, an email draft, a calendar event or Wi-Fi login details. Phones decide what to offer based on the format. A web address opens a browser prompt; Wi-Fi details offer to join a network. Either way, your phone shows you what it found and waits for you to confirm, so read that prompt rather than tapping through.

How much data fits in a QR code?

A lot less than people expect for a clean scan. The biggest codes hold a few thousand characters, but the more data you pack in, the denser and harder to read the grid becomes. That's why marketing codes use a short link instead of a long address: a short link makes a chunkier, more forgiving pattern that scans quickly from a few feet away, even from the back of a laptop lid across a café table.

How can you spot a suspicious QR code?

Look at the surroundings first. A code on a parking meter, a parcel you didn't order or an unexpected letter deserves more doubt than one on a brand's own shop window. Then check the preview address: odd spellings, extra words or a long string of random characters are warning signs. If you're unsure, search for the company yourself and go to its real site instead of the code.

Questions people ask

Can a QR code hack my phone just by scanning it?
Scanning only reads text. Harm usually comes from opening a malicious link or entering details on a fake page, so check the address before you tap.
Do QR codes expire?
A static code never expires, but the page it points to can disappear. A dynamic code can stop working if the service behind it is switched off or unpaid.
Can someone track me by scanning a QR code?
The site you open can see ordinary web details like device type and rough location, as any website can. The scan doesn't give it your contacts or files.
Why won't my QR code scan?
Common causes are a code that's too small, low contrast, glare, a curved surface or no blank border. Make it larger and flatter.
Are free QR code generators safe?
Static codes from a generator are fine. Be careful with free dynamic codes, which can stop working or add ads if you stop paying.
